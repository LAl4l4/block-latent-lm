# 候选选题：预测寄存器需要为未来学习吗？

查新日期：2026-10-30。状态：推荐做低成本预实验，尚无实验结果；不保证新颖性穷尽或发表。

## 核心问题

在带预测寄存器的自回归 Transformer 中，保持模型能读取的信息不变，仅阻断未来 token 的损失经指定注意力边更新历史预测寄存器的隐藏表示，能否改善当前预测与最终验证损失？

这是对 State-Prediction Separation（SPS）机制解释的针对性检验，不是提出寄存器、stop-gradient 或 myopic training。

## 查新与边界

1. [The State-Prediction Separation Hypothesis](https://arxiv.org/html/2607.01218)，2026。已提出每个文本 token 后插入预测槽，并对比保留全部预测槽、窗口化预测槽、交换持久状态等方案。也有梯度范数分析，不能说作者没有机制证据。其注意力窗口同时改变前向可见信息和反向路径；在本次审查的正文、附录与检索结果中，未找到保持相同前向函数、仅限制预测槽隐藏状态反向路径的直接对照。
2. [Do Language Models Plan Ahead for Future Tokens?](https://arxiv.org/html/2404.00859)，2024。已提出 myopic training，保留前向计算但阻断未来损失对过去状态的梯度，并测量梯度方向。因此这些实验工具本身不是新贡献。
3. [Understanding the Emergence of Seemingly Useless Features in Next-Token Predictors](https://arxiv.org/html/2603.14087)，2026。已研究未来损失、参数共享与特征学习，也在小语言模型上做相关干预。不能声称首次研究未来梯度的作用。

潜在贡献仅限于：利用已有干预工具，辨别 SPS 双流结构中预测槽的未来梯度作用，并确定原机制解释的适用边界。它是新颖性风险中等偏高的窄机制研究，不是已确认的新架构选题。

## 最小实验

先用同一小模型、数据、初始化和训练调度，比较三组：

| 组别 | 前向可见性 | 训练梯度 |
|---|---|---|
| A：完整寄存器 | 历史文本和历史预测槽均可读 | 正常反传 |
| B：SPS 零窗口 | 历史文本可读，历史预测槽不再供后续位置读取 | 正常反传 |
| C：只限制预测槽反向路径 | 与 A 完全相同 | 历史预测槽被未来位置读取时，仅其源隐藏状态停止梯度 |

零窗口优先用于清楚定义干预，不冒充复现论文默认窗口为 64 的全部结果。窗口大于零时，截断远距离直接边仍会留下近距离中继路径，应另行研究。

先做一轮配对种子筛选；出现可测信号后补到至少三个种子。总预算允许时再加普通 Transformer 和相匹配的其他梯度屏蔽对照。不要在初始结果不明显时扩充大量配置。

模型起点：约 5–10M 参数、同一个 8K 词表、短上下文。先利用现有 TinyStories 数据做筛选，若有稳定效应再扩展一个模型尺寸或普通文本数据。单一 TinyStories 结果不足以声称通用语言模型结论。

## 实现中的必要区分

- 同一参数和输入下，A 与 C 的 logits、loss 和前向隐藏状态应在数值误差内一致。训练后参数不同，输出自然会不同。
- 对选中的读取边使用 `W_K(stop_gradient(h))`、`W_V(stop_gradient(h))`，而不是直接停止已投影 K/V 的全部梯度。前者保留共享投影参数的直接更新；两种干预的含义不同。
- 预测槽自己的预测损失路径保留，历史文本状态的梯度保留；每层都处理指定跨位置边。
- 零窗口时，针对早期预测槽隐藏状态计算较晚位置损失的 Jacobian，确认被切断；同时确认当前损失和文本状态梯度未误切。
- 不能分别对不同注意力分支 softmax 后简单相加；必须保持共同归一化和原前向数值。可参考 myopic attention 的实现，再做角色选择性扩展。
- 共享参数仍会从其他位置接收梯度；本实验不是关闭所有未来 token 对所有模型参数的学习。
- 记录梯度范数、裁剪率和实际吞吐；梯度干预可能改变优化幅度，也可能比普通 attention 更慢。

## 测量与解释

主要指标：独立验证集 token NLL、各随机种子的配对差值。辅助指标：固定层和位置上当前损失与后续损失的梯度范数及余弦、实际训练时间与显存。

- C 优于 A：支持指定预测槽反向路径的限制在该设置下有用，不能单凭此证明梯度冲突是唯一原因。
- B 优于 A，而 C 不优于 A：说明该反向干预不足以复现窗口方案的收益，不能直接断言收益全部来自前向限制。
- C 明显更差：说明该设置中的预测槽也从未来监督获益；不是对所有规模 SPS 结论的反证。
- B 在小规模下没有稳定优势：当前预算没有建立待解释现象，应暂停扩大机制结论。

## 一两天预算与停手条件

第一阶段完成前向等价、梯度路径、因果遮罩测试，并对最慢实现做短时测速。依据端到端时间决定 token 预算，不沿用现有 GRU 的秒/步估计新 attention 实现。

第二阶段运行配对筛选，只有出现超过测量噪声的差异才追加种子。若实现不能保持前向等价、预计超出 36 GPU 小时、损失仍在剧烈变化且预算不足、或结果完全落在种子波动内，停止论文级扩展。
