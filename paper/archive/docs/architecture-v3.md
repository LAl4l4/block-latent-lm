# Latent AR：codec 预训练 + 下一块预测 V3

更新日期：2026-10-29。本文描述当前默认实现；[V1](docs/architecture-v1.md)、[V2](docs/architecture-v2.md) 已归档。当前完成训练与同步推理代码，未完成正式主干训练、多模态扩展或异步加速验证。

## 1. 目标与这次调整

长期目标：统一 latent 主干决定内容和细节，下游轻量 decoder 翻译成文本、图像、音频。主干继续生成 latent，不等待解码出的文本回灌。多模态训练是否改善其世界理解，需要后续单独实验。

V2 从零联合训练，在自由展开 16 个 latent 后仅用文字 CE 监督，实测出现标点和高频词重复。诊断发现模型使用了条件且梯度存在，不能简单归结为 decoder 完全忽略 latent。此次先建立可还原的文本表示，再训练主干，分别检查 codec、下一块预测、自主回灌三个环节。

当前使用普通因果 Transformer + 单次线性输出，不使用 flow matching。它是确定性连续预测基线，尚不是能采样多个完整内容方案的 latent 条件分布模型。

## 2. 模块与形状

令每块最多 K=4 token，词表 V=8192，latent 宽度 D=512。

```text
真实 token 块 [B, 4]
    ↓ E：词 embedding + 四位置拼接 + 有效标记 + MLP
真实 latent [B, 512]

prompt latent U + 历史 latent z
    ↓ F：8 层因果 Transformer，宽度 512，8 heads
hidden [B, T, 512]
    ↓ A：Linear(512, 512)，预测标准化坐标
预测 latent [B, T, 512]
    ↓ 还原真实 latent 坐标
    ↓ D：每块独立展开 [4, 256]，1 层双向 self-attention + FF
词表分数 [B, T, 4, 8192]
```

| 模块 | 参数 | 阶段一 | 阶段二 |
|---|---:|---|---|
| Codec encoder + decoder（共享词表权重） | 4,266,240 | 更新 | 冻结 |
| Latent Transformer | 27,271,680 | 不建立 | 更新 |
| 线性 latent 输出头，含 bias | 262,656 | 不建立 | 更新 |
| 阶段二合计 | **31,800,576** | — | **27,534,336 可训练** |

Codec 的输入 embedding 与 decoder 词表投影共享参数以减少重复权重。解码仍须经过 latent；共享参数不建立输入 token 到输出的旁路。

## 3. 阶段一：建立可还原表示

对来自训练故事的真实小块 x：

```text
z = E(x, 有效长度)
logits = D(z)
L_codec = CE(logits, x)，忽略 padding
```

Encoder 在小块内同时看到四个真实 token，这是重建阶段的正常输入。它把各位置 embedding 和有效槽位标记拼接后，用 MLP 映射到一个 512 维向量。最后不足四 token 的块显式标记有效长度。

Decoder 唯一的内容输入是 z。把 z 线性展开成四个 256 维位置，追加局部位置向量，经一层双向 self-attention 和 SwiGLU，再投影到词表。这里不输入真实 token embedding、先前 token、其他块或 prompt 旁路。

四个槽位互相可见，`attn_mask=None`、`is_causal=False`。实现将 `[B,T,4,256]` 折叠成 `[B×T,4,256]`，不同块之间物理隔离。阶段一虽由真实文本构造 z，但阶段二预测 z 的主干不会读取当前目标块。

数据从故事中有放回采样随机起点，通常取四 token，25% 概率主动请求 1～4 token 的短块，并保留自然尾块。只有故事自然结束才包含 EOS，不在随机截断处伪造 EOS。

codec 进入条件为固定 2,048 个 dev 块上 token 准确率 ≥99%、完整四 token 全对率 ≥95%。同时记录含短块的全对率；进入条件只用完整四 token 指标，避免短块抬高结果。质量检查发生在新 prior 输出目录创建之前。

## 4. 阶段二：真实历史上的下一块预测

阶段一结束后固定 E、D，并将 codec 保持在 eval 状态。将 prompt 编码为 U，将真实续写块编码为 z1…zT。

```text
h1 = F(U) 的最后一个有效状态
h2 = F(U, z1) 的新增状态
h3 = F(U, z1, z2) 的新增状态
…
预测标准化 z_t = A(h_t)
```

训练输入是 `[U, z1, …, z_(T-1)]`，监督目标是 `[z1, …, zT]`。这些位置通过因果 mask 一次并行计算，相当于普通 Transformer 将输入与目标错开一位。预测 z_t 时只能看到 prompt 和 z_<t。目标块 encoder 独立工作；不会把未来块信息混入前一块。

实际 batch 中 prompt 长度不同。物理 padding 留在前缀内，用 key 有效 mask 排除；目标位置的 RoPE 编号按各样本真实 prompt 块数接续。预测第一块从最后一个有效 prompt 状态取值，其余从对应真实历史块状态取值，不能直接用统一物理尾位置。

### 坐标标准化与损失

仅从 4,096 个训练小块估计每一维 μ、σ，σ 最小值为 0.1。统计冻结并写入 prior 断点：

```text
n(z) = (z - μ) / σ
预测 n(z_t) = A(h_t)
预测 z_t = 预测 n(z_t) × σ + μ

L_latent = 所有有效块上 mean_D((预测 n(z_t) - n(z_t))²) 的平均
L_text   = 所有有效目标 token 上 CE(D(预测 z_t), x_t) 的平均
L_prior  = latent_mse_weight × L_latent + token_ce_weight × L_text
```

两个权重默认都为 1.0。每次累计更新分别使用整个累计 batch 的有效块总数和有效 token 总数作分母；不等长 microbatch 不被错误地等权平均。padding 块和 -100 标签不参与损失。

Codec 参数 `requires_grad=False`，真实编码过程 `no_grad`；但预测 z 经过 D 的路径必须保留计算图。否则文字 CE 无法给 F/A 梯度。阶段二不会更新或重新拟合 codec。

验证分别记录 latent MSE、文字 CE，以及把样本历史状态循环错配后的同类指标。正确条件比错配条件更好可以说明使用了条件，不能证明续写连贯。当前 CE 不是普通逐 token 自回归似然，不将其转换成可与 V1 直接比较的 PPL。

## 5. 自主推理与阶段三检查

实际推理不读取真实续写：

```text
U                       → F/A → 预测 z1
U, 预测 z1               → F/A → 预测 z2
U, 预测 z1, 预测 z2        → F/A → 预测 z3
…
预测 z1,z2,z3…           → 冻结 D → 文本
```

主干反馈的是自身预测的真实坐标 latent；不用文字先解码再重新编码。每一步直接一次线性预测，没有噪声初始化和积分循环。生成 16 块需要一次 prompt prefill 和 15 次带 KV cache 的新增位置计算。

参考生成先算出预算内的 latent，再局部并行解码；默认贪心，屏蔽 PAD/BOS，按每行首个 EOS 停止展示。`min_new_tokens` 可以显式屏蔽过早 EOS；不是质量修复。随机词采样不反馈到主干，可能与后续已确定内容不一致，所以先检查贪心输出。

`evaluate_rollout.py` 对固定 dev 窗口同时计算真实历史分支和自主分支，输出短文本、逐步标准化 RMS、两分支距离、有限值检查和重复率。第一块的两分支应相同；之后的差异用于定位回灌漂移。真实历史分支不作为实际推理效果；向量距离也不作为语义质量分数。所有预算内 latent 均参与数值检查，包括已解码出 EOS 之后的位置。

第一阶段重建正确并不保证第二阶段预测到 codec 能可靠解码的区域。MSE 在多个合法未来之间可能趋向平均；真实历史训练也有训练/推理分布差异。这次先测量这个简单基线，不能预先宣称上述问题解决。

## 6. 数据、预算和断点

复用固定抽取的 100,000 篇 TinyStories，训练/dev/test 含 EOS 分别为 21,997,870 / 2,334,755 / 2,357,072 token。dev/test 各 10,995 篇；词表仅由训练子集拟合。codec 归一化统计同样只来自 train。

两个阶段默认各 10,000 个优化步、batch 128×累计 2、BF16。阶段一每步 256 个小块，阶段二每步 256 个故事窗口，每窗口最多 64 目标 token。抽样有放回，不等于遍历一遍数据；真实计数保存在 `tokens_seen`、`blocks_seen`。

每 100 步自动保存，正常结束和第一次 Ctrl+C 额外保存。原子替换 `last.pt`，包含模型、优化器、scaler、数据 RNG、torch/CUDA RNG、步数和有效 token/块计数。prior 断点内包含完整冻结 codec、训练统计、源 codec 哈希及进入检查结果，可以独立恢复。精确恢复检查使用相同设备类型和训练配置；改变 batch 或步数计划会改变轨迹。

当前架构标记为 `block_codec_v1` / `latent_codec_ar_v3`。V1/V2 以及早期 flow 实验权重继续由加载器按历史实现严格读取，不能直接恢复为当前 prior。历史 flow 代码只用于旧权重兼容，不是训练选项。

## 7. 后续扩展

异步执行可将 F/A 作为生产者、D 作为消费者，以有界队列连接，EOS/取消只作控制信号。当前尚未实现该队列，也没有单卡并行加速结论。

图像和音频后续需要对应模态的可重建表示、轻量还原器，以及进入共享主干的训练任务；仅增加 decoder 不能自动让现有文本 latent 携带足够的图像、音频细节。视觉生成训练能否提升世界理解，以及在相同预算下相对文本模型的收益，都应作为实验问题检验。
