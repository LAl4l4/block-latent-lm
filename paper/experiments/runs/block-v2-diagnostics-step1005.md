# V2 第 1,005 步：高频词与标点退化诊断

日期：2026-10-29。读取现有检查点，不更新权重或改动训练配置。完整数值见同目录 `block-v2-diagnostics-step1005.json`。

## 观察

固定 dev 的前 128 个故事窗口，目标最多 64 token，共 5,334 个有效目标 token。所有条件使用完全相同的 prompt、窗口和标签。

| 条件 | CE | 说明 |
|---|---:|---|
| 正常生成 latent | 5.658 | 当前模型 |
| 每个序列的时间均值 latent | 5.725 | 均值重复到所有生成块，包含完整序列信息 |
| 换成同批其他故事的 latent | 6.263 | 在 batch 内循环错配整段 latent |
| 平滑 unigram | 5.992 | 在 4,096 个训练窗口上估计高频词分布，不使用 prompt |
| 全零 latent | 16.303 | 强烈分布外输入，不宜作为质量基线 |

正常 latent 的 top-1 准确率约 7.67%。第一个检查窗口首位置的最高概率 token 为句号（约 16%），其次为 `and`、逗号等。它们反复成为各位置概率最高的输出，因此贪心续写出现标点和常用词的重复。

各位置组正常 / 均值 CE：

| 输出位置 | 正常 | 均值 |
|---|---:|---:|
| 1–4 | 5.074 | 5.570 |
| 5–16 | 5.653 | 5.719 |
| 17–32 | 5.785 | 5.788 |
| 33–64 | 5.718 | 5.722 |

均值扰动的影响主要集中在前四个 token；后半段的数值变化很小。由于均值包含未来生成 latent，这是一项离线扰动诊断，不直接量化 rollout 的因果收益。

## 排查范围

- 相邻 latent 的平均余弦相似度约 0.956，不同 prompt 同位置 latent 的平均余弦约 0.201。不能把现象解释成所有 prompt 都产生同一个 latent。
- 单独用两个 dev 窗口反传，encoder、backbone、latent head 和 decoder 的梯度范数分别约 3.82、0.75、0.55、1.83，均有限且非零。没有发现梯度链被截断的迹象。
- 换错故事的 latent 明显提高 CE，说明 prompt 条件确实被利用；但正常模型相比 unigram 仍只获得有限改进。
- 代码测试通过不等于开放式续写任务已被学好。固定样本过拟合检查不能替代该验证。

## 对训练目标的解释

当前 `z_t` 完全由 prompt 和之前的确定性 latent 得到。四个输出位置虽在 hidden 空间双向交互，但词表预测不以任何实际选择的输出 token 为条件。因此模型的生成分布是给定 prompt 后，各位置词表概率的乘积。

开放续写的未来存在多种合理词句。当前目标要求模型在没有目标相关随机变量或实际词历史的情况下预测这些未来位置，容易学习边际高频词分布。这个解释与观察一致，但本次诊断不能证明增加训练永远无效，也不能完全排除其他优化问题。

后续可研究先建立“具体文本块 ↔ latent”的重建关系，再训练主干建模这些 latent 的条件分布，使主干能够选择一条具体续写路径，decoder 负责还原。仅加入与答案无关的随机噪声，或强制抑制重复，不保证解决训练目标问题。该后续方案尚未实现或验证。

相关研究：[Non-Autoregressive Neural Machine Translation](https://arxiv.org/abs/1711.02281) 展示的并行生成并非只删去自回归依赖，还结合了蒸馏、latent 变量与其他训练机制；其翻译结果不能直接继承到本项目的开放式故事生成。
