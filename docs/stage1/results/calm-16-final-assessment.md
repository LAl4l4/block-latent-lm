# CALM-16：10000步训练后评估

确认最后检查点 `runs/calm-16/last.pt` 的 step 为10000，最终验证及保存完成。共见113,634,109个目标token（有放回窗口采样，不能当作独立语料token量）。没有修改训练配置、模型权重或启动新训练。

## 判断

当前模型学到了可测的条件依赖，但文字生成仍不合格，不适合直接作为反馈蒸馏教师。蒸馏反馈只能近似其回灌，不会补上教师尚未学会的内容生成能力。

7500到10000只降约0.0265，最后阶段收益很小；这只描述该预算下的曲线，不能推断任何更长训练一定无效。

训练中验证为固定64个窗口、208个块。额外以512个固定窗口（1597个块，23360个目标token）重新评价最终模型：Energy 26.2109，条件优势1.5755。Brier前缀奖励1至4词为[0.053225, 0.006329, 0.001284, 0.0]，是命中项减碰撞项的两样本Monte Carlo估计，不是准确率；不能将4词估计为0解释成任何4词组合都不可能生成。

独立64块诊断共用目标后验样本，预测每组8个、目标每块100个：

条件模型在这一批优于无条件bank，但没有估计置信区间。后验参考提前知道未来，不是语言模型可达到的下界。与第700步同诊断协议对比，条件预测26.8775→26.0641，说明不是完全没有学习。

## 自由生成

用最终检查点，在CUDA/BF16下对4个TinyStories风格prompt分别使用42/43/44三个seed，共12条、每条最多64新token。采用一次latent抽样、decoder逐位置argmax与真实文本压缩回灌；不包含官方200候选温度筛选。

人工检查12条都存在明显语法或连贯性问题，出现词语拼接、异常字符或不相关内容。改变prompt但保持相同seed时，多条输出共享大量词序及模板。例如seed42的4个不同prompt，输出都在38个新token后EOS，且多次出现类似“Dave … Gra … said Lily”的片段。说明这些样本中随机噪声主导的模板很强；不能据此量化整个模型的条件信息。

这只是小规模定性检查，不能替代系统语言质量基准，也不能据此断言CALM路线不可行。

## 建议的下一步

先用独立小实验核实已知少量固定文本能否被完整训练链拟合并正确解码，再做相同训练配方下4-token与16-token的控制对照，以区分实现/优化问题与扩块、表示及数据预算问题。本轮不启动这些训练。当前证据不支持直接进入反馈蒸馏或仅靠继续降低Energy就宣称成功。
