## 想法本身

每块 L 个词（本项目 L=16）。

1. **块内从右往左生成**：先生成第 L 个词，最后生成第 1 个词。
2. **相邻块的开始时间错开 s 个局部解码步**（例如 s=L/2）。
3. **局部解码器可以 attention 到前面各块里已经生成出来的词。**

这样一来，块与块的衔接处（第 t 块的首词）最后才生成，而这时第 t−1 块已经写完。

### 可见性（精确结论）

第 t 块第 j 个词的生成时刻是 s·t + (L+1−j)。它能看到第 t−m 块第 j′ 个词，当且仅当后者生成得更早：

\[
j' > j - s\,m .
\]

于是被丢掉的依赖（两个词谁也看不到谁）只出现在 j′ ≤ j − sm 的词对上。它们之间的距离是

\[
mL + j - j' \;\ge\; m(L+s) \;\ge\; L+s .
\]

**倒序加错开 s 步时，丢掉的依赖距离一律 ≥ L+s。** 当 L=16、s=8 时，就是 ≥24 个 token。

作为对比，**正序加错开 s 步**时，被丢掉的是 j′ ≥ j + sm 的词对，距离 ≤ m(L−s)，最小可以到 1。紧挨着衔接处的依赖恰恰被丢掉了，所以倒序这一步是必需的。现有的延迟反馈方案（第 t 块只看到 ≤t−2 块）丢掉的也是距离 1 到 L 的依赖。

### 和主干的关系

第 k 块在 s·k + L 时刻完成。第 t 块开始时，已经写完的块是 k ≤ t − L/s。

- **s = L/2 时**：主干只看到 ≤t−2 块，这与现在延迟组的信息条件完全相同，同时有两块在跑，并行度和双块调度一样。差别只在于衔接处交给局部 attention 处理，丢掉的依赖从相邻词挪到了 24 个 token 以外。
- **s 更小时**：同时在跑的块有 L/s 个，并行度更高，但主干更滞后，局部窗口也要覆盖更多块。

### 性质

- **因果、可流式：** 每个词只依赖它左边的文字和主干状态，从不读右边的块。KV cache 只增不改，不需要草稿和验收。
- **训练和推理一致：** 训练时用 attention mask 表达"谁比谁先生成"，推理时就按这个顺序生成。
- **代价：** 块内是非从左到右的顺序，会带来学习难度；被丢掉的远距离依赖也有一点损失。

### 判断

- **不是新的：** "相距远、依赖弱的词可以并行"这一原则（PAR、ZipAR、DiagD），以及块间错开、重叠的流水线（ZipAR、TeCoP、FlowBlock）。块边界问题本身也已被 PSF 和 ZipAR 指出。
- **未见先例：** 在一维文本里，用**块内倒序**加**错开 s 步**，把衔接处排到最后处理，并给出"丢掉的依赖距离一律 ≥ L+s"的精确保证，同时保持因果、可流式、训练与推理一致。ZipAR 指出的首词缺口、PSF 用非因果着陆目标绕开的边界问题，都可以用这个顺序直接消除。
- **注意：** 检索有限，2026 年下半年块级并行文本生成的论文增长很快。"没找到"不等于"不存在"。投稿前要通读 PSF、TeCoP、FlowBlock、MultiBD 全文，并补查 delay pattern 与任意顺序自回归（σ-GPT 一类）。

**结论：值得做，有发表空间。** 贡献的定位是"顺序设计"，配一条可证明的距离保证，再加实证。能不能发，取决于实验能否证明倒序把首词代价大幅压下去，并且优于正序错开和 PSF 式的着陆目标。在目前的规模（TinyStories、约 5000 万参数）下，更现实的是 workshop 或 arXiv。想投主会，需要更大的模型或更强的数据。

## 验证计划

1. **调度代价实验（与架构无关，先做）。** 训练一个 token 级小 Transformer，只用 attention mask 表达各调度"谁能看到谁"：预测来自只含位置的查询，内容流按生成时间因果。各组同预算、从头训练，比较自然语料 CE。

   | 组 | 丢掉的依赖距离 |
   | --- | --- |
   | 普通因果 LM | 无（上界） |
   | 延迟块（≤t−2） | 1 到 L |
   | 正序错开 s=8 | 1 到 8 |
   | **倒序错开 s=8** | ≥24 |
   | 倒序错开 s=4 | ≥20，并行 4 块 |
   | PSF 式着陆目标 | 只重叠一个词 |

   判定：如果倒序错开 s=8 的代价远小于延迟块（现有块级系统里延迟代价是 0.381 nat），就做第 2 项；如果和正序差不多，这个想法就不成立。

2. **接入现有块级系统。** 局部头改成倒序，加上读前一块已生成词的局部 attention；用 GRU 选的词作为最终输出（去掉 VAE 那一环，以便逐词流式读取）；主干保持 ≤t−2 的延迟条件。与 [paper-plan.md](paper-plan.md) 第 1 步的四组同初始化、同预算对照，报告第二块和首词的代价、生成样例、延迟。
3. 3 个 seed；s ∈ {L, L/2, L/4} 的并行度与质量曲线。
