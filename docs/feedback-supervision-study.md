# 反馈蒸馏监督信号：预先固定的诊断方案

本轮保留原教师与所有旧结果，先补足失败原因的证据，再判断监督应怎样改。全部Python命令统一使用 `D:\Code\venv313\Scripts\python.exe`。只顺序使用GPU，不启动并行训练。

## 教师、划分和数据

教师为 `runs/feedback-distill-greedy/data/teacher.pt` 的固定step10000快照。greedy与随机教师共用权重；随机组仅将GRU选词温度改为0.8，top-k保持50。当前生成链仍包含GRU选词、VAE均值编码、实际解码文字与历史encoder。

greedy数据使用16,384篇train、512篇dev、128篇prepared test；原始数据已经对train/dev/test作故事去重和分离。dev选检查点，test用于最终诊断及生成，不反向用于调参。原教师也只以dev作验证。

每个样本保留当前h、真实反馈r、预先抽取的u、当前块以前实际喂入的反馈、源prompt、下一块实际文字及EOS掩码。当前反馈与未来文字不得进入历史预填充。

## 数据量和容量

训练故事数1,024 / 4,096 / 16,384，MLP宽512 / 1024，均为两层残差MLP。固定seed2032、batch256、3,000次更新；报告准确有效块数、参数量、最佳dev步数和最终误差。

这是六个配置的探索性对照，不足以拟合普适scaling law。更新数相同时，大数据组的平均样本重复次数更少，必须同时报告这一预算差别。

## 固定历史的误差注入

在同一教师历史上，用真实反馈r推进作为参考。比较学生误差方向、同范数随机方向和反馈自身方向，缩放系数固定为0、0.25、0.5、1、2。

记录反馈MSE、下一块固定词前缀下的教师分布KL、教师实际词的CE变化和第一词argmax变化。CE标签来自教师生成，不是自然语料真值。固定历史排除了反馈改变后后续访问状态不同的混淆，但不能单独证明完整闭环的唯一失败原因。

## 损失对照

固定同一个基线最佳检查点，分别继续训练MSE与“下一块教师分布KL＋0.1 MSE”各500步。主比较预先固定的last500，避免用dev MSE挑选行为蒸馏检查点而偏向坐标损失。best仍按dev MSE保存作为诊断，不能用test重新选择步数。

核心对照增加训练seed，记录seed间差异。行为梯度经冻结主干与冻结局部GRU传到学生预测反馈，不更新教师权重。这里使用的下一块token前缀固定为同一个教师前缀，KL不含离散采样的反向梯度。

## 访问状态对照

以同一个学生在新增训练故事上生成并重新询问冻结教师，收集学生访问状态中的真实反馈标签。与同一批新增故事的teacher轨迹比较；两臂共享旧训练标签，并下采样到完全相同的新增有效反馈块数。两臂从相同初始化微调，使用相同预算。

这一轮on-policy数据没有真实反馈分支的下一块反事实词标签，因此只用于MSE，不混入行为损失实验。

## 共享采样噪声

每块开始前抽取16维均匀随机数u，GRU每个位置用对应u作逆CDF选词。学生提前读取同一个u；对照学生结构相同，但输入恒为0.5（居中后为零）。train/dev/test的采样随机流应独立，闭环再使用未用于采集的固定随机种子。

这提供的是配对随机选择，而不是预先标注好的语义方向。另在固定h上多次改变u，检查实际输出多样性；比较配对u、不配对u和隐藏u，判断学生是否确实利用随机输入。反馈误差只汇总完整、非EOS且需要继续的块，同时单独报告终止结果，避免把继续条件过滤隐藏起来。

## 闭环指标与边界

使用相同test prompt、教师权重、采样温度及共享随机流，比较真实反馈与学生反馈。报告完整/去除首块的token匹配、共同前缀、EOS/长度、学生访问状态误差及实际文字。首块一致只是实现检查；token不一致不自动等于语义变差。

所有模型/数据选择都需可追溯；保留逐prompt与逐样本结果以支持配对分析。当前生成仍串行计算真实解码与反馈作诊断，不宣称异步加速。
